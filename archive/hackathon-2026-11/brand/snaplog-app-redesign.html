Why this redesign

  • Thumb zone: primary actions sit in the bottom 240px; destructive/secondary up top.
  • Sun-readable: Ink on Paper 15.8:1, Ink-on-Orange primaries, 16px minimum type, 48px targets.
  • Honest states: skeletons, empties with next action, errors with retry, low-confidence flags — never silent.
  • Scoped: no accounts, billing, ordering, or extra categories anywhere in the flow.

Tokens → Tailwind v4 @theme

Single source of truth for React + Vite + Tailwind v4 + shadcn new-york. Paste into app.css after @import "tailwindcss". Body = system stack; IBM Plex Mono via @fontsource/ibm-plex-mono (bundled npm package — never a network link) for labels, numbers and prices only; Georgia/Times for headings.
