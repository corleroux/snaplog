# Criteria: ordering

AC-01 Given a customer views the public catalogue When they select an item variant Then they can add it to a cart with a quantity [ui]

AC-02 Given a customer has items in their cart When they view the cart Then all items, quantities, and totals are shown [ui] [data]

AC-03 Given a customer checks out When they submit customer details Then an order is created with status "new" [ui] [data]

AC-04 Given a buyer views orders When they open the orders page Then all orders are listed with customer, total, and status [ui] [data]

AC-05 Given a buyer views an order When they open it Then the order items, quantities, and customer details are shown [ui] [data]

AC-06 Given a buyer marks an order as fulfilled When they save Then the order status changes to "fulfilled" [ui] [data]

AC-07 Given a buyer cancels an order When they confirm Then the order status changes to "cancelled" [ui] [data]

AC-08 Given a customer adds an item that is out of stock When they try Then they are prevented or warned [ui] [manual]
